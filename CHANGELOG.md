## 🚀 Uso Rápido

```bash
# Clonar repositorio
git clone https://github.com/ka0tic0/arch-bspwm-setup.git
cd arch-bspwm-setup

# Hacer ejecutable
chmod +x install-bspwm.sh

# Instalar
./install-bspwm.sh

# Cambiar tema (opcional)
bash themes/dracula-theme.sh

# Personalizar (opcional)
bash scripts/customize.sh

# Iniciar BSPWM
startx
```
